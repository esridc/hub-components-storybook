Card Callbacks

A callback function can be passed into the gallery, and it be called for each result, passing in the IHubCardViewModel, Context and Search Result and must return an updated IHubCardViewModel. This allows Gallery instances to customize the card display beyond the standard outputs.

Includes and Enrichments

We can ask the search system to include additional information, which it then available for use in the callback function. The format is enrichment{.deep.path} AS propertyName

  • Item: metadata, groupIds, ownerUser, org
  • Server: server, layers
