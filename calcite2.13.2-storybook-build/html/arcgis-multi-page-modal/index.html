What's New on Search?
Gallery View
Your thumbnails: front and center. We’ve added a new gallery view for a more visual way to browse search results. The traditional list is still available with the additional metadata fields and will be the default view when a user comes to the search page.
Enhanced Filters
Filters now show the count of items, and categories reflect the nested hierarchy established in ArcGIS Online.
Keeping Layers Together
We are no longer splitting out layers as individual items. The search result count will now reflect the actual number of items, not inflated by separate layers.
Classic View
This new search experience is in beta and we’re working to incorporate additional features, like autosuggest in the search bar and source and license filters.
